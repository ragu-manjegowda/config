# Terminal-friendly math

When explaining mathematics in chat, write equations as readable plain text (Unicode symbols are fine). Use a `text` code block for multi-line equations or when alignment helps. Do not use LaTeX math delimiters (`$...$`, `$$...$$`, `\(...\)`, or `\[...\]`) or LaTeX commands for display math; they appear as raw text in this OpenCode TUI. If the user explicitly requests LaTeX source or you are quoting/editing LaTeX, preserve the requested syntax.
